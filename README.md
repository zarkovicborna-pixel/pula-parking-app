# pula-parking-app

**Sastav tima:**
* Borna Žarković
* Antun Grgić

**Ustanova:** Tehnički Fakultet u Puli (https://tfpu.unipu.hr)  
**Kolegij:** Programsko inženjerstvo  
**Mentor:** doc. dr. sc. Nikola Tanković  

**Kratki opis funkcionalnosti:**  
Aplikacija za prikaz parkirališta u Puli s predikcijom popunjenosti, izračunom očekivanog vremena vožnje u minutama od trenutne GPS lokacije korisnika, vizualizacijom ključnih gradskih znamenitosti i opcijom unaprijed plaćanja karticom.
